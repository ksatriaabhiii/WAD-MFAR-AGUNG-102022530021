VOUCHER SHOPKU - VERSI PERBAIKAN

CARA MENJALANKAN:
1. Ekstrak folder voucher_shopku_fixed ke C:\xampp\htdocs\voucher-shopku
2. Jalankan Apache dan MySQL dari XAMPP Control Panel.
3. Buka http://localhost/voucher-shopku/tabel_voucher.php untuk menyiapkan tabel.
4. (Opsional) Buka http://localhost/voucher-shopku/insert_voucher.php untuk memasukkan 3 data contoh.
5. Halaman pengguna: http://localhost/voucher-shopku/
6. Halaman admin CRUD: http://localhost/voucher-shopku/data_voucher.php

CATATAN:
- Database db_shopku dibuat otomatis oleh koneksi.php.
- File index.html lama diganti menjadi index.php agar voucher diambil dari MySQL.
- Jika sudah ada index.html di folder proyek, hapus/pindahkan file itu agar halaman utama index.php yang dibuka.
- Konfigurasi default XAMPP: user root, password kosong.
- Tombol Klaim di halaman pengguna hanya menampilkan status; proses klaim akun belum dibuat karena belum ada sistem akun/pengguna.
